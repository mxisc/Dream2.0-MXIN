Dream 2.0 MXIN is a responsive anime-inspired classic blog theme reconstructed for WordPress from Nineya's Dream 2.0 design.

== Description ==

Dream 2.0 MXIN provides responsive article cards, configurable sidebars,
dark mode, archive and link page templates, native WordPress comments,
menus, widgets, and appearance settings.

This is an independent WordPress reconstruction based on Dream 2.0 by Nineya.
It is not an official WordPress edition of the upstream Halo theme.

== Installation ==

1. Upload the theme folder to /wp-content/themes/ or install the ZIP in Appearance > Themes.
2. Activate Dream 2.0 MXIN.
3. Assign a menu to the Primary Menu location.
4. Configure the theme under Appearance and add widgets to the sidebar areas.
