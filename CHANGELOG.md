# Changelog

All notable public changes to Dream 2.0 MXIN are documented here.

## Unreleased

- Merged the WordPress.org-safe theme files into the main theme source tree.
- Removed the separate theme distribution overlay from the development repository.
- Removed legacy development preview images from the public theme package and kept `screenshot.jpg`.
- Kept private comments, comment emojis, friend-link administration, SMTP notifications, and mail logs in the optional Plus plugin.

## 0.8.0 - 2026-08-10

- Split private comments, comment emojis, friend-link management, SMTP notifications, and mail logs into the optional Dream 2.0 MXIN Plus plugin.
- Added a clean theme package that works without the companion plugin and makes no optional third-party service requests.
- Added complete third-party library attribution.

## 0.7.41

- Changed the WordPress theme distribution license to GPLv2 or later while retaining upstream MIT attribution.
- Added the required WordPress.org `readme.txt` file.
- Internationalized frontend, widget, comment, sharing, settings, link, and mail-log interface strings.
- Verified activation and frontend rendering with WordPress 7.0.2 and PHP 8.3.

## 0.7.40

- Removed the Moments content feature and unused legacy assets.
- Added WordPress.org-compatible theme metadata and documentation.
